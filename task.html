Project Overview

This website demonstrates deployment of a static website delivered through a Content Delivery Network (CDN) using HTTPS.

HTTPS Enabled

Secure access using SSL/TLS encryption.

CDN Distribution

Content served from edge locations for faster delivery.

Static Hosting

Lightweight and scalable architecture.

Cache Strategy

HTML files are cached for 5 minutes to allow content updates.

Static assets such as CSS, JavaScript, and images are cached for 30 days to improve performance and reduce origin requests.
